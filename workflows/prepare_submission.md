# Workflow: Prepare the Hack the Change submission

**Objective:** A submission that passes prescreen. Deadline: Sunday Nov 8, 11:30 AM Calgary time. Aim for 11:00.

**Steps**
1. Run `bash tools/check.sh`. It must pass.
2. Confirm all demoed code (web and `mobile/`) is committed to the one GitHub repo.
3. README: what it does, how to run web and iOS, what is fictional or simulated, and **every AI tool used** (required; undisclosed AI use can disqualify).
4. Devpost title format: `Team ID - Team Name - Project Name`.
5. Devpost must include: description, all team members, GitHub link, a 2–5 minute demo video.
6. Name Prompt 2 and the focus areas we address in the first lines of the description.
7. Produce a checklist of anything the human must do by hand (record video, add members, click submit). Claude does not submit forms.

**Edge cases**
- A feature that only half works: cut it from the demo and say so in the README rather than demo it broken.
