# Good Neighbour

Good Neighbour is a Prompt 1 prototype that helps Calgarians find small, low-pressure ways to connect and discover support. It links to real Calgary Public Library and City of Calgary resources; it does not claim to show live event availability or make bookings.

Open `index.html` in a modern browser. Filter ideas, save one to your plan, mark it complete, and revisit it after refreshing. The plan is stored in the browser's local storage on the current device and is removed when browser data is cleared. No account or API key is required. Fonts, icons, the library image, and provider pages require an internet connection; the core plan and filtering work without them once the app files are available.

This is a prototype, not a medical service or crisis line. Content and links should be reviewed with local community partners before deployment, and providers should be checked for up-to-date eligibility, accessibility, schedules, and availability. It does not collect analytics, provide live matching, or connect people directly.
